# DemasGram (Larpogram)

Клиент Telegram Desktop на базе AyuGram с собственными доработками.

## Скачать

Релиз [v7.0.9](https://github.com/ceofamed/larpogram/releases/latest) · Windows ([AyuGram.exe](https://github.com/ceofamed/larpogram/releases/download/v7.0.9/AyuGram.exe))

## Функции
- добавлнение подарков в себе в профиль при нажатии на них на маркете(подарить подарок->подарить себе->выбрать подарок(обязательно улучшеный)->нажать на любой подарок на маркете
- антикраш от стикеров,эмодзи
- менять подарки (только локальные)
- Локально дарить подарки
- Локальные подарки
- Свой номер телефона, основной и дополнительные @username на карточке профиля
- Клик по локальному коллекционному номеру открывает его карточку
- Исправлен клик по номеру телефона с пробелами
- Исправлена загрузка и предпросмотр подарков
- Полный Ghost Mode
- История сообщений
- Anti-Recall — защита от удаления сообщений
- Настройка шрифтов
- Стример-режим
- Локальный Telegram Premium
- Переводчик
- Улучшенный внешний вид
